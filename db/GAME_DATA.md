# 게임 데이터 시트로 갱신하기

위키 대신 게임 파일에서 직접 뽑은 값(게임 데이터 시트)으로 사이트 수치를 확인하고 바꾸는 방법입니다.
게임 데이터 시트는 hd2-modding 저장소의 `소스/자료/게임시트/` 에 있고, 게임이 설치된 PC 에서 그 저장소의 `도구/game_sheets.py` 가 게임의 데이터 표(`data/game/*.dl_bin`)와 공식 문장표로 만듭니다.
위키보다 확실한 이유: 게임이 실제로 쓰는 표를 그대로 읽으므로 위키 편집 지연, 오기, 옛 판 값이 없습니다. 게임 업데이트 직후에도 바로 다시 뽑을 수 있습니다.

## 순서 (게임 업데이트 뒤)

1. hd2-modding 저장소에서 공식 문장표와 시트를 다시 뽑음(게임 있는 PC): `도구/game_names.py` → `도구/game_sheets.py`
2. 이 저장소로 가져옴: `node scripts/tools/import-game-strings.mjs <official_strings_us_ko.tsv> --planets <행성.json>`(이름, 행성), `node scripts/tools/import-game-sheets.mjs <소스/자료/게임시트>`(수치)
3. 차이 보기: `node scripts/tools/compare-game-sheets.mjs` → `db/source/game_sheets/diff.md`
4. 차이를 보고 사이트 값을 게임 값으로 바꿈 → `npm run check`

`compare-game-sheets.mjs` 는 사이트를 바꾸지 않고 보고서만 씁니다. 지금은 아래 '바꾸는 길' 의 빌드 스크립트가 아직 위키 원본(`db/source/wiki_*.json`, `*_data.json`)을 읽으므로, 게임 값으로 바꾸는 것은 항목마다 사용자 확인 뒤 진행합니다(AGENTS.md 의 데이터 원칙을 바꾸는 일이라).

## 계속 위키에서 받는 것

- 게임 파일에 없는 것(2026-11-25 확인): **부스터, 작전 제한 조건, 함선 모듈, 임무 정의**. 이름과 설명 문장은 게임 문장표에 있지만, 그 문장을 쓰는 표가 데이터 표(dl_bin 55개)에도 게임 리소스 약 4만 9천 개(텍스처, 소리 제외)에도 없습니다. 암호화된 게임 코드(game.dll) 안에 있는 것으로 보여, 수치(부스터 효과량, 모듈 비율 등)는 위키 값을 유지합니다. 이름의 한국어는 지금처럼 게임 문장표로 맞춥니다
- 상태 이상 표(`generated_status_effect_settings`)와 작전 변수 표(`generated_modifier_settings`), 임무 시나리오 표(`generated_scenario_settings`)는 숫자만 있고 이름과 짝을 지을 단서가 없어 뽑지 않았습니다
- 아이콘과 그림, 전쟁 채권 가격과 페이지, 슈퍼 스토어, 공략 요령(위키 본문), 패치 기록, 방어구 장갑 등급과 속도 수치, 아직 미확인인 칸(`game_sheets/README.md` 마지막 절)

## 바꾸는 길 (사용자 확인 뒤 한 화면씩)

1. 각 `build-*.mjs` 가 게임 시트를 먼저 읽고, 게임에 없는 칸만 위키 원본을 쓰게 바꿈(값마다 `source: 'game'` 또는 위키 판 번호를 남김)
2. `test-*.mjs` 의 위키 스냅숏 대조를 '게임 시트와 같음' 대조로 바꿈
3. AGENTS.md 데이터 원칙에 '수치는 게임 데이터 시트가 먼저, 없으면 위키' 를 적음
